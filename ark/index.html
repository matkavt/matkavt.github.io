Бункер: Ковчег

Игра для компании. Мест в бункере меньше, чем вас.

Как это работает

Ведущий создаёт партию и называет код из восьми символов. Остальные вводят его у себя — и у всех собирается одна и та же игра: та же катастрофа, тот же бункер, те же персонажи по тем же номерам мест. Интернет не нужен вообще: партия целиком выводится из кода арифметикой, одинаковой на любом телефоне.

Частые вопросы

У нас разные партии по одному коду. Как так?
Так быть не может, если код введён верно, — проверьте символы. В коде нет букв I, L, O и U: их путают с единицей, нулём и V. Если партии всё же разошлись, напишите нам с обоими кодами, это важная ошибка.
Можно ли посмотреть чужого персонажа?
Приложение не покажет. Ведущий раздаёт ключи мест — четыре цифры, — и без ключа чужое место не открывается. Это защита от любопытства, а не от злого умысла: сервера нет, и все расчёты идут на самом телефоне.
Сколько нужно игроков?
От 4 до 19. Мест в бункере обычно берут половину стола.
Партия прервалась, телефон перезагрузился.
Персонаж и круг сохраняются: откройте приложение, партия продолжится с того же места.

Политика конфиденциальности

Bunker: Ark

A party game. The shelter has fewer seats than you have people.

How it works

The host creates a game and reads out an eight-character code. Everyone else types it in — and the same game assembles on every phone: the same disaster, the same shelter, the same characters in the same seats. No internet is needed at all: the whole game is derived from the code by arithmetic that comes out identical on any device.

Questions

We entered one code and got different games. How?
That cannot happen if the code was typed correctly — check the characters. The code contains no I, L, O or U: they get confused with one, zero and V. If the games still differ, write to us with both codes; that is a serious bug.
Can someone peek at another player's character?
Not through the app. The host hands out seat keys — four digits — and without the key someone else's seat will not open. It guards against curiosity, not against determined cheating: there is no server, and every calculation happens on the phone itself.
How many players are needed?
From 4 to 19. The shelter usually holds half the table.
The game was interrupted and the phone restarted.
Your character and the current round are saved: open the app and the game continues where it stopped.
